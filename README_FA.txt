پروژه ویجت ساعت سه شهر (تهران، استانبول، شانگهای)

ویژگی‌ها:
- ساعت مستقل ۲۴ ساعته برای هر شهر
- تاریخ میلادی و شمسی
- ظاهر سفید با گوشه‌های گرد و برچسب آبی
- ویجت صفحه اصلی اندروید

نکته مهم:
این فایل‌ها سورس پروژه هستند، نه فایل APK آماده. برای ساخت APK به کامپیوتر با Android Studio نیاز است.

ساخت APK:
1) Android Studio را نصب کنید.
2) از File > Open، پوشه WorldClockWidget را انتخاب کنید.
3) صبر کنید Gradle Sync تمام شود.
4) از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) را بزنید.
5) فایل APK معمولاً در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.
6) APK را به گوشی منتقل و نصب کنید.

افزودن ویجت:
1) برنامه را یک بار باز کنید.
2) روی صفحه اصلی گوشی لمس طولانی کنید.
3) Widgets را انتخاب کنید.
4) «ساعت سه شهر» را پیدا و به صفحه اصلی اضافه کنید.

یادداشت:
به‌روزرسانی هر دقیقه توسط AlarmManager درخواست می‌شود، اما ممکن است MIUI برای صرفه‌جویی باتری به‌روزرسانی را عقب بیندازد. اگر ساعت متوقف شد، در تنظیمات باتری برای برنامه محدودیت پس‌زمینه را بردارید.
